# Templates and extensions

Start from a genre, or add themes, scripts, sounds and templates others made.

## 1. Templates

File → New from Template: Techno, House, Drum & Bass, Liquid DnB, Hardgroove, IDM, Hip-hop. Eight bars each, with a kit, a beat, a bass, chords, a loop from the pack and a mixer set up.

## 2. Extensions

Preferences → Extensions installs a .ravunext from a file or the gallery. Its themes join the theme list, its scripts the palette, its templates New from Template, its sounds the browser.

## 3. Make one

A .ravunext is a zip: extension.json (name, version, author, about) and folders themes, scripts, templates and sounds. Nothing else in it is unpacked.

## 4. Updates

Ravune asks GitHub for the latest release when it starts (Preferences → Extensions turns that off) or on Help → Check for Updates. When a newer one is out, Preferences → Extensions shows it: Update downloads it and swaps it in, Restart now opens it. A copy installed for all users on Windows runs the new installer on restart instead.
