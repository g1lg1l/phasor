# Record and export

From the song to files: a mixdown, stems, or a project for another DAW.

## 1. Record

The record button captures what plays into a new clip on the playlist.

## 2. Export

File → Export renders the song as WAV (16, 24 or 32-bit float), FLAC, Ogg or MP3 (with ffmpeg). The format picked last keeps the export key.

## 3. Stems

File → Export → Stems… writes a file per mixer track, with its reverb and delay tails, ready for mixing elsewhere.

## 4. Other DAWs

File → Export → DAWproject… carries notes, audio and the mixer to Bitwig, Studio One, Cubase and others; File → Open reads a .dawproject back.
