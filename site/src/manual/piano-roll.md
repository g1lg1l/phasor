# Piano roll

Melodies, chords and basslines for the selected channel, in the current pattern.

## 1. Draw

Click to draw, drag to move, drag the right edge to resize; snap follows the zoom (Alt: free). Hold the right button to erase. Ctrl+drag selects several, then drag them together.

## 2. Stay in key

Set the song's key and scale on the piano roll's toolbar; with Fold to scale on, new and moved notes snap to it. Chord stamp draws a whole chord with one click.

## 3. The lane underneath

VEL, PITCH, BRIGHT and AUTO pick what the bars below edit: velocity, a note's pitch bend, its brightness, or a knob automated inside the pattern.

## 4. Tools

Quantize, legato, strum and humanize work on the channel's notes. Scripts adds arpeggios, Euclidean rhythms, random basslines in key, reverse, half and double time.

## 5. Play it in

The computer keyboard plays the channel (A–K notes, Z / X octave, C / V velocity), and so does any MIDI controller: plug it in, it's picked up.
